## 文件

- `checkerboard_9x6_1920x1080_130px.png`：1920×1080 屏幕用的棋盘格，**10×7 个方格 / 9×6 个内角点**，每格 130px。
- `checkerboard_9x6_preview.png`：聊天/手机预览用。

## 用法

1. 在 1920×1080 的显示器上**全屏、等比**显示大图，不要拉伸填满。
2. 用尺子量 **5 个连续方格的总长**，再除以 5，得到实际方格边长（米）。
3. 运行标定：

```powershell
conda activate cv_env
python scripts/calibrate_camera.py --square-size 0.0366
```

> `0.0366` 是按你的显示器 EDID（约 54×30cm）+ 1920×1080 + 130px 方格估算出来的，
> **仍必须用尺子实测替换**，不要直接照抄。

4. 采集 15–25 张，覆盖画面四角和边缘；按 `ESC` 开始标定。

## 注意

- Ace Pro 关闭人脸跟踪/自动变焦。
- 避免屏幕反光和摩尔纹；必要时拉远一点或换角度。
- 标定分辨率和后续运行分辨率保持一致（建议 1280×720 或 1920×1080）。
